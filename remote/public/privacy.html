Datenschutz

Couch Remote (Chrome-Extension und Handy-App) · Stand: September 2026

Couch Remote macht das Handy zur Fernbedienung für Netflix im Browser auf PC oder Mac. Es gibt kein Konto, keinen eigenen Server, keine Werbung und kein Tracking. Der Entwickler erhält keine Daten.

Welche Daten verarbeitet werden

In der Extension (am PC)

  • Sie liest ausschließlich auf www.netflix.com, was dort angezeigt wird: Titel, Bilder-Adressen, Fortschritt, Profilnamen, Wiedergabestatus (Position, Lautstärke, Ton- und Untertitelspur).
  • Diese Informationen gehen nur an das gekoppelte Handy – direkt oder Ende-zu-Ende verschlüsselt über einen Relay (siehe unten). Sie werden nicht gespeichert und an niemanden sonst übermittelt.
  • Lokal gespeichert werden nur die Einstellungen: eine zufällige Geräte-ID, der Kopplungsschlüssel, der Name des Rechners und gegebenenfalls eigene Serveradressen.

In der Handy-App

  • Lokal im Browser gespeichert werden die Kopplungen (Geräte-ID, Schlüssel, Rechnername, Serveradressen).
  • Der Kopplungsschlüssel steht im #-Teil des QR-Code-Links; dieser Teil wird von Browsern nie an einen Webserver gesendet.
  • Bilder von Titeln lädt das Handy direkt von Netflix. Dabei gelten die Datenschutzbestimmungen von Netflix.
  • Bewertungen (optional): Nur wenn du in den Einstellungen einen eigenen OMDb-Schlüssel einträgst, schlägt das Handy die Titel nach, die du öffnest: zuerst bei Wikidata die IMDb-Nummer zur Netflix-Nummer des Titels, dann bei OMDb die Bewertungen (notfalls über den Titelnamen). Beide Dienste sehen dabei deine IP-Adresse und die jeweiligen Titel, OMDb zusätzlich deinen Schlüssel. Schlüssel und Ergebnisse bleiben auf dem Handy gespeichert (Ergebnisse bis zu einer Woche).

Beteiligte Dienste

Damit Handy und PC sich ohne eigenen Server finden, nutzt Couch Remote öffentliche Dienste. Diese sehen technisch bedingt die IP-Adressen der Geräte, aber keine Inhalte:

DienstZweckWas er sieht
PeerJS-Server (0.peerjs.com)Verbindungsaufbau zwischen Handy und PCIP-Adressen, zufällige Geräte-IDs, technische Verbindungsdaten
STUN-Server von Google (stun.l.google.com)Ermitteln der öffentlichen Adresse für die DirektverbindungIP-Adressen
TURN-Server von PeerJS (*.turn.peerjs.com)Weiterleitung, falls keine Direktverbindung möglich istIP-Adressen; die Daten sind per WebRTC (DTLS) verschlüsselt
MQTT-Relay HiveMQ (broker.hivemq.com)Ausweichweg in Netzen, die Direktverbindungen sperrenIP-Adressen und verschlüsselte Nachrichten (AES-GCM mit dem Kopplungsschlüssel); keine Inhalte
OMDb (www.omdbapi.com), nur mit eigenem SchlüsselBewertungen von IMDb, Rotten Tomatoes und MetacriticIP-Adresse, dein OMDb-Schlüssel, Namen der geöffneten Titel
Wikidata (query.wikidata.org), nur mit eigenem OMDb-SchlüsselZuordnung Netflix-Nummer → IMDb-NummerIP-Adresse, Netflix-Nummern der geöffneten Titel; siehe Datenschutz der Wikimedia Foundation
GitHub PagesAusliefern der Handy-AppIP-Adresse und übliche Server-Protokolldaten, siehe Datenschutzerklärung von GitHub

Alle Server lassen sich in der Extension unter „Erweitert“ durch eigene ersetzen.

Rechtsgrundlage und Rechte

Die Verarbeitung dient allein der vom Nutzer gewünschten Funktion (Art. 6 Abs. 1 lit. b bzw. f DSGVO). Da der Entwickler keine personenbezogenen Daten erhält, kann er dazu auch keine Auskunft geben; für die oben genannten Dienste gelten deren Datenschutzbestimmungen. Alle lokal gespeicherten Daten verschwinden, wenn die Extension entfernt bzw. die Website-Daten der Handy-App gelöscht werden.

Privacy

Couch Remote (Chrome extension and phone app) · Last updated: September 2026

Couch Remote turns a phone into a remote control for Netflix in a desktop browser. There is no account, no own server, no ads and no tracking. The developer receives no data.

Data processed

  • The extension reads only what www.netflix.com displays (titles, image URLs, progress, profile names, playback state) and sends it only to the paired phone, directly or end-to-end encrypted through a relay. It is not stored or shared with anyone else.
  • Stored locally: a random device ID, the pairing key, the computer's name and optional custom server addresses (extension); the pairings (phone app). The pairing key travels in the # part of the QR code link, which browsers never send to a web server.
  • The phone loads title images directly from Netflix; Netflix's privacy statement applies.
  • Ratings (optional): only if you enter your own OMDb key in the settings, the phone asks OMDb (www.omdbapi.com) for the titles you open, after looking up their IMDb id by Netflix id at Wikidata (query.wikidata.org). Both see your IP address and those titles, OMDb also your key. Key and results (up to a week) stay on the phone.

Third-party services

To connect phone and computer without an own server, Couch Remote uses public services that technically see the devices' IP addresses but no content: the PeerJS server (0.peerjs.com, connection setup), Google's STUN server (address discovery), PeerJS TURN servers (fallback forwarding, WebRTC-encrypted), the HiveMQ public MQTT broker (fallback relay, messages AES-GCM encrypted with the pairing key) and GitHub Pages (hosting the phone app). All servers can be replaced under “Erweitert” (advanced) in the extension.
